# ⏳ Countdown Timer

A sleek and fully responsive countdown timer built with HTML, CSS, and JavaScript. Set your desired time and get notified with an alarm when the countdown reaches zero.

## 🚀 Features

- ✅ Set custom countdown duration
- ✅ Responsive design — works seamlessly on all screen sizes (desktop, tablet, mobile)
- ✅ Plays alarm sound when the time is up
- ✅ Smooth UI with modern styling
- ✅ Toggle settings panel for timer adjustments

## 📱 Responsive Design

The application works smoothly on all devices and its controls are optimized for both touchscreens and desktop use."

## 🔊 Alarm Feature

Once the countdown ends, an audio alert will play automatically — useful for productivity, workouts, or reminders.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (Flexbox, Media Queries)
- **JavaScript (Vanilla)**
